# Drive filing

The default filing location is the owner's `AI_PROJECTS/Miranda` folder in Google Drive. The exact folder link is recorded in the README on `main` in the private `404-ac-notfound/miranda-lessons` repository. If the log is inaccessible, find `Miranda` beneath the exact `AI_PROJECTS` parent through the owner's connected Drive. Verify the folder identity and applicable access before uploading. If the project designates a different Drive delivery folder, follow that instruction.

## File automatically when the deliverable is final

- Use the confirmed final version, including a file the user identifies as final or a delivery-ready file Miranda clears on a publication review. Drafts, review notes, sample proofs, and source materials stay at their working locations unless the user explicitly asks to file them. Preserve format and filename unless the project specifies a naming convention.
- Use authorized Drive access for the owner's designated folder. The standing instruction covers filing this deliverable without a separate approval. Respect project restrictions on where files may be stored and who may see them. Keep all sharing and permissions as they are.
- Check the destination for the same final version using its existing Drive ID, a content checksum when available, or reliable version metadata. Use the existing link when the approved final is already in the designated or established project delivery folder. Otherwise upload the approved file, or copy an existing Drive item when a filing copy is needed. Preserve the original. If a same-name file has different content, follow the project convention or use a versioned filename. After an interrupted upload, check the destination before retrying.
- Verify the resulting file in the intended folder and return its Drive link or one short in-character receipt. If the file or a write-capable Drive connection is unavailable, report the specific pending upload after looking for an authorized route. Complete any available Git lesson write independently and report the two outcomes accurately.

The Drive folder holds files. GitHub holds the short lessons. Keep file uploads out of the Git repository and lesson entries out of Drive.
