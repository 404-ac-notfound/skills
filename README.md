# Shared skills

Shared skill/lens repository for 404-ac-notfound projects.

- [The Editor-in-Chief](the-editor-in-chief/SKILL.md) gives publication verdicts and edits for articles, chapters, posts, decks, and image briefs. Its [benchmark library](the-editor-in-chief/references/benchmark-library.md) shows what Good, Great, and Amazing look like in each format.

Use the whole skill folder in venues that support Agent Skills. In a venue that takes instructions or attachments, give it `SKILL.md` and its `references/` folder, then supply the draft and, if known, the audience and destination. Use the same revision of the folder across venues.

Moving existing KEYSTONE lenses here requires the separate S3 move PR, its review, and Andrew's approval of the new pin (see KEYSTONE `cabinet/urahara/findings/repo-structure-decision-2026-10-25.md`).
